# ContextDeck v1.0.0

Status: **stable installer prepared; final installer homologation pending**.

The v1.0.0 Windows distribution uses the existing electron-builder 26.0.12
NSIS x64 configuration. It keeps the legacy `%APPDATA%\\Project Dock M00`
profile, `persist:project-dock-m00-chat` Chromium partition, and
`project-dock-m00` Herdr session. Projects is enabled by default.

Known limitations:

- Herdr is an external dependency.
- The installer is unsigned and has no publisher identity.
- Authenticated suspension remains conservatively disabled when safety evidence
  is insufficient; automatic and forced suspension are unavailable.
- There is no automatic update mechanism.

The final installer checksum and automated results are recorded in the M01-R3
validation report. The `v1.0.0` Git tag is intentionally not created by this
preparation branch.
